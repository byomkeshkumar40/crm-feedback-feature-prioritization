# Resume Bullets (all figures computed from the SYNTHETIC project data)

- Analyzed 1,500 synthetic CRM feedback records from 326 accounts with Python/Pandas, separating feedback volume from unique affected customers and identifying unreliable contact imports (102 records, 86 accounts) as the top complaint theme.
- Built a RICE prioritization model for 12 CRM feature opportunities with documented estimates, scenario analysis (8 scenarios) and a 5,000-trial Monte Carlo test; the top-ranked feature held rank #1 in every scenario.
- Wrote a 17-section PRD for the top-ranked feature (reliable CSV import) with user stories, acceptance criteria and measurable success metrics, and delivered an Excel workbook and 3-page Streamlit dashboard on the same analysis.
